# Getting Started with MDX

MDX is a powerful format that lets you write JSX in your Markdown documents. This makes it perfect for creating rich, interactive blog posts.

## Why MDX?

MDX combines the simplicity of Markdown with the power of React components. You can:

- Write content in Markdown
- Embed React components directly
- Create interactive examples
- Build custom components for your content

## Basic Markdown Features

Here's what you can do with MDX:

### Lists

- First item

### Code Blocks

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

You can add [links](https://example.com) and images just like in regular Markdown.
